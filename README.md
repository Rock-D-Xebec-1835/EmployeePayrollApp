# Employee Payroll Management System

## Overview

The Employee Payroll Management System is a modular Java application designed to demonstrate real-world object-oriented programming concepts through progressive use cases.

Each use case introduces new architectural patterns and concepts while building on previously implemented features.

## Architecture Goals

* Demonstrate object-oriented design principles
* Maintain clean separation of responsibilities
* Introduce scalable service-based architecture
* Simulate enterprise-grade application structure

## Technology Stack

* Java
* Object-Oriented Programming
* File Persistence
* Collections Framework
* Regular Expressions

## System Modules

### Use Case 1 – Employee Registration

Handles employee creation and validation.

Concepts:

* Encapsulation
* Validation
* Object creation

### Use Case 2 – Authentication & Login

Implements role-based authentication.

Concepts:

* Inheritance
* Polymorphism
* Session management

### Use Case 3 – Payslip Generation

Calculates payroll details.

Concepts:

* Aggregation
* Composition
* Service layer

### Use Case 4 – Payslip Download

Creates immutable payslip copies.

Concepts:

* Immutability
* Cloning
* File persistence

### Use Case 5 – Dashboard Display

Displays personalized dashboards.

Concepts:

* Interfaces
* Factory Pattern
* Runtime behavior selection

### Use Case 6 – Input Validation

Centralizes input validation using exception hierarchies.

Concepts:

* Custom exceptions
* Regex validation
* Fail-fast validation

## System Workflow

1. Register employee
2. Authenticate user
3. Generate payroll
4. Download payslip
5. Display dashboard
6. Validate inputs
